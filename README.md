# Анализ русскоязычных текстов

**Python · морфология · анализ тональности**

Текстовый анализатор выполняет токенизацию, лемматизацию, определение частей речи, выделение значимых слов и словарную оценку тональности. Учитываются отрицания, усилители и ослабители. Формируются частотная таблица, статистика и, по запросу, графики.

```bash
python3 -m pip install -r requirements.txt
python3 analyzer.py examples/sample.txt
python3 analyzer.py examples/sample.txt --output-dir results/example --plots
python3 -m pytest -q
```

`--output-dir` задаёт новую папку результатов; без него статистика выводится в консоль. Морфологический анализатор создаётся при обращении к нему, а запись файлов выполняется только при явном запуске CLI. Можно подключить словарь CSV с колонками `term;value` через `--dictionary`. Встроенный маленький словарь демонстрационный.

Проект выполнен в рамках практикума по анализу неструктурированных данных. Программную реализацию целиком выполнил Егор Пугачев.
